# OBS Music Dock 🎵

Нативный C++ плагин для OBS Studio. Выводит на стрим стильный виджет с текущим треком прямо из Windows (поддерживает Яндекс.Музыку, Spotify, Chrome, VK и др.).

## Установка
1. Скачайте архив из [Releases](https://github.com/axalame/obs-music-dock-plugin/releases).
2. Откройте архив и зайдите в папку `obs-music-dock`.
3. Скопируйте папки `bin` и `data` в корневую папку вашего OBS Studio (туда, куда он у вас установлен, по умолчанию это `C:\Program Files\obs-studio\`), подтвердив слияние папок.
4. Перезапустите OBS.

## Использование

**1. Панель настроек (Dock):**
* В верхнем меню OBS: `Док-панели` -> `Пользовательские доки браузера`
* Имя: `Music Settings`, URL: `http://127.0.0.1:18789/index.html`

**2. Виджет на стрим (Overlay):**
* В источниках добавьте `Браузер` (Снимите галочку "Локальный файл").
* URL: `http://127.0.0.1:18789/overlay.html`
* Установите ширину 1920 и высоту 1080 (виджет сам адаптируется).
* Включите: `Обновлять браузер, когда сцена становится активной`.

*(Дизайн полностью настраивается в панели: 4 темы, Ambilight-свечение, масштаб, скругление, цвета).*
