# OBS Music Dock 🎵

Красивый и современный плагин для OBS Studio, который отображает текущий воспроизводимый трек. Работает нативно (на C++) без скриптов на Python, перехватывая медиаданные прямо из Windows (Яндекс.Музыка, Spotify, VK Музыка, браузеры и др.).

## Особенности 🌟
- **4 уникальные формы виджета:**
  - 🔮 **Aura Glass (Классика)**: стильное стекло с размытием заднего фона и аккуратными тенями.
  - 💿 **Vinyl Record (Винил)**: круглая пластинка, которая эффектно вращается, пока играет музыка, и замирает на паузе.
  - 📏 **Minimalist (Минимализм)**: строгий дизайн без размытия, с квадратной обложкой и четким текстом.
  - 💊 **Compact Pill (Капсула)**: крошечный, аккуратный виджет в стиле "Dynamic Island" из iOS.
- **Подсветка Ambilight**: фоновое свечение автоматически подстраивается под цвета обложки трека.
- **Полная кастомизация**: меняйте масштаб, ширину, скругление углов, цвета и прозрачность. Настройки скинов универсальны и работают на всех формах.
- **Умная автоматика**: виджет плавно выезжает при смене трека и прячется через заданное время.
- **Нативное C++ ядро**: все настройки сохраняются надежно и работают молниеносно без нагрузки на систему.

## Установка 🚀
1. Скачайте свежий .zip архив со страницы [Releases](https://github.com/axalame/obs-music-dock-plugin/releases).
2. Закройте OBS Studio.
3. Откройте скачанный архив и распределите файлы по папкам OBS (обычно OBS установлен в C:\\Program Files\\obs-studio\\):
   * Файл **obs-music-dock.dll** (лежит в архиве в папке in\\64bit) скопируйте по пути:
     👉 C:\\Program Files\\obs-studio\\obs-plugins\\64bit\\
   * Файлы дизайна **index.html** и **overlay.html** скопируйте по пути:
     👉 C:\\Program Files\\obs-studio\\data\\obs-plugins\\obs-music-dock\\ 
     *(если папки obs-music-dock там нет — просто создайте её)*.

## Настройка в OBS ⚙️
### 1. Добавляем Панель Управления (Dock)
1. В верхнем меню OBS выберите: Док-панели -> Пользовательские доки браузера.
2. Введите название: Music Settings.
3. В поле URL вставьте: http://127.0.0.1:18789/index.html
4. Нажмите Применить. Закрепите панель в удобном месте интерфейса.

### 2. Добавляем виджет на стрим (Overlay)
1. В нужной сцене OBS добавьте новый источник: Браузер (Browser Source).
2. Назовите его Music Player.
3. Снимите галочку "Локальный файл".
4. В поле URL вставьте: http://127.0.0.1:18789/overlay.html
5. Установите ширину 800 и высоту 400 (виджет адаптируется под размер внутри этого окна).
6. **ОБЯЗАТЕЛЬНО** поставьте галочку Обновлять браузер, когда сцена становится активной.
